AdventureWorks Sales Dashboard using Excel

An interactive sales dashboard built in Excel from the AdventureWorks 2012 dataset, using Power Query for data transformation and pivot tables to power a set of linked visualizations.

What was done
Cleaned and transformed the raw data using Power Query
Built pivot tables summarizing total sales by country and quarter, with slicers for interactive filtering (e.g., by product color)
Designed a dashboard combining 6 chart types: sales by country, order volume by category, monthly sales trend, top 6 products by revenue, sales by territory, and order volume by shipment method
Tools

Excel · Power Query · Pivot Tables · Slicers · PivotCharts

Deliverables
Excel workbook (.xlsx) with Power Query transformations, pivot tables, and dashboard sheet
